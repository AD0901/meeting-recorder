开始使用前，你可能想知道

录音后需要手动整理吗？

设备录音或本地上传的音频都会自动转写并生成纪要，还可同时上传文档补充背景。之后可以继续向 AI 提问，也可以手动校正并保存。

能区分不同发言人吗？

可以。纪要会按发言人整理原文与发言占比，方便回顾每个人的观点和讨论过程。

手机上可以查看吗？

可以。首页与会议页面都支持手机浏览器，摘要、待办和全文会针对小屏幕调整排版。
